# CV refresh (Nov 2026): before and after

Screenshots for the content update that matches the site to the 2026-11-25 CV. Captured with Playwright
from `npm run dev`, reduced motion, at 1280x800 (a short-laptop screen, where every quest card is one
full-width row), 1440x1100 (the main-quest grid) and 390x844 (phone). Classic pixel site = `/?classic`;
live site = `/` (option F, `?hour=12&wx=clear`).

- `before/`: main quests Nechita Raka, Aside, Sommelier; Fit Check and Leet-For-Berger as side quests;
  Wolt Clone in coursework.
- `after/`: main quests Nechita Raka, Fit Check, Aside, Sommelier Bot, Leet-For-Berger; Wolt Clone the
  first side quest; skills and the About text from the CV. `live-viewport-*` show the two new voxel
  totems on the live site (caught mid-build, as the cubes fly in).
